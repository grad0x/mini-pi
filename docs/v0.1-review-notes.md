# Mini Pi v0.1 Review Notes

## Acceptance scope

The deterministic fix-bug demo verifies Mini Pi's Harness execution path. It
does not measure LLM reasoning quality and does not introduce a real provider,
network request, API key, or provider SDK.

## Known design debt

### Run completed does not mean durable committed

`Agent` emits `run_finished(completed)` before `SessionRuntime` persists the
new messages. Agent Run completion therefore does not guarantee durable commit.
A future durable Harness will need an explicit durability boundary. v0.1 does
not change this ordering or add a durable operation abstraction.

### `blocked` has coarse semantics

A policy denial and a fail-closed `beforeToolCall` infrastructure error can
both report that the effect was blocked. Future auditing may need a more precise
disposition such as `allowed`, `denied`, `gate_error`, or `execution_error`.
v0.1 preserves the current event contract.
